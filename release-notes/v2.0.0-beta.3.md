# Black Mango 2.0, test build 3

## New

- **Windows.** The first Windows test build. Download the Setup .exe: it installs just for you (no admin password), adds Black Mango to the Start menu, can add a desktop shortcut, and keeps itself up to date like the Mac version.
- Open in VLC works on Windows too.

## Good to know

- To bring your accounts, favorites and history over from a Mac, use **Settings > Data > Export backup** there and **Import backup** on Windows.
