# Black Mango 2.0, test build 5

## New in this build

Steadier live channels when a provider keeps dropping the connection:

- No blocky picture after a reconnect. When the stream comes back from a different server, or with footage missing, Black Mango holds the last clean picture (the sound keeps going) until the next full frame.
- Black Mango tries to reconnect to the same stream server first, and stops trying once a provider shows it never allows that, so reconnects are quicker.
- Channels that keep dropping can build up to 30 seconds of cushion. It only grows when the channel actually stalls.
- If the provider offers HLS, a jumpy channel switches to it on the same account and remembers that. If HLS doesn't show a picture within 12 seconds, Black Mango goes straight back.
- If a channel keeps jumping, a note tells you, and Black Mango switches to the same channel on another of your accounts when one has it.
- **Settings > Fixes for flaky channels** shows how many channels have extra cushion or HLS, and resets them all.

## Also included (from test build 4)

- Stalker accounts on Windows send your real time zone, so guide times line up.
